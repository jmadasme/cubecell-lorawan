# rec/ — video explicativo

Este directorio contiene el video asciinema de **CubeCell como puente serial a LoRaWAN** y el reproductor
que se usa en la página del proyecto.

- `cubecell-lorawan.cast`: grabación original (asciicast v2).
- `cubecell-lorawan.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:05. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
